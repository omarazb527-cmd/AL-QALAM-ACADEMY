قائمة الطلاب والعملاء المسجلين

يتم تحديث القائمة لحظياً بمجرد تسجيل أي طالب جديد في الموقع.

إضافة أو تعديل تخصص أكاديمي (مثل: علوم شرعية، فقه، أصول دين...)

أي تخصص تضيفه هنا سيظهر تلقائياً في فلاتر المعلمين على الموقع وفي قائمة اختيار تخصص المعلم عند إضافة أو تعديل المعلمين.

1. إضافة أو تعديل دورة / مسار تعليمي

2. تحديد وتعديل أسعار باقات وعدد الحصص (4، 8، 12، 16 حصة...)

إضافة أو تعديل بيانات معلم / معلمة

إضافة أو تعديل رأي عميل / طالب

إضافة أو تعديل منهج (مثل: نور البيان، الأجرومية...)

التصنيفات (المجالات)

إضافة أو تعديل برنامج للأطفال

الصورة: الصق رابط صورة مباشر (https). إن تركته فارغًا تظهر الأيقونة التعبيرية. اكتب كل هدف/موضوع/كتاب/مهارة في سطر مستقل.

إضافة أو تعديل فيديو شرح قصير

ارفع الفيديو على يوتيوب (يفضّل «غير مدرج» Unlisted) أو Vimeo ثم الصق الرابط هنا، أو استخدم رابط ملف mp4 مباشر. سيُشغَّل الفيديو داخل الموقع.

طلاب أنشأوا حسابات. فعّل الاشتراك وحدّد المعلم ليظهر في لوحة الطالب.

إضافة صورة متحركة تفاعلية

ارفع الملف داخل مجلد في مستودع GitHub (مثلًا media/) والصق رابطه هنا، أو استخدم أي رابط https مباشر لصورة. الصور تتحرك عند اللمس أو الضغط، وتتوقف تلقائيًا لمن فعّل "تقليل الحركة" في جهازه.
